orch - the single controller for coding agents, in any plexer.
'orch help <command>' (or 'orch <command> -h') prints usage, doctrine, and every flag.

OBSERVE
  orch status [flags]                           Fleet table with cost and context. The default command.
  orch monitor [flags]                          Push stream of the states an orch acts on. Arm it as a Monitor.
  orch events [flags]                           Every state transition, mid-turn flips included.
  orch questions [flags]                        Agents blocked on a question.
  orch runs [<target>] [flags]                  Dispatch history, newest first.
  orch logs [flags]                             Structured diagnosis records. --json emits raw records.

DISPATCH
  orch dispatch <target> "<prompt>" | --file <path>|- [flags]
                                                Send a task onto a clean session. Durable.
  orch answer <target> "<text>" [flags]         Answer the question the agent is asking.
  orch steer <target> <text...> [flags]         Mid-run instruction. The reply says if it applied.
  orch broadcast "<text>" <target>... | --all [flags]
                                                Steer several.
  orch pipe <target> <target> ["<instruction>"] Hand the first agent's result to the second.
  orch model <target> <model[:thinking]> [flags]
                                                Change the model.
  orch wait <target> [flags]                    Block until one agent reaches a state.

COLLECT
  orch result <target>... [flags]               Each target's result. --json prints one array, one entry per target.
  orch tail <target> [flags]                    Last session entries.
  orch peek <target> [flags]                    What is on the pane screen now.
  orch session <target>                         Session path and stats.

QUEUE
  orch queue <add|list|history|cancel|edit|take-on|reap|intake>
                                                Durable task queue.
  orch work [flags]                             Assign queued tasks to idle agents.

REVIEW
  orch review <list|approve|reject>             Review done worktree agents.

AGENTS (never steals focus except 'focus')
  orch spawn <name>... [flags]                  One fleet, one command. The names are the agents.
  orch tile <tab> <name> [flags]                Add one named agent to an existing tab.
  orch rename <target> <name> [flags]           Set the agent name. --pane sets the border label.
  orch reset <target>... | --all [flags]        Fresh session, same agent (alias: new).
  orch reload <target>... | --all [flags]       Live-reload code after a rebuild.
  orch restart <target>... | --all [flags]      Relaunch the harness process.
  orch close <target>... | --all [flags]        Close (alias: kill).
  orch abort <target> [<text...>]               Cancel the current turn, then steer with the text.
  orch detach <target> [flags]                  Release the lease. The agent keeps running.
  orch adopt <target> | --all [flags]           Take an unleased agent.
  orch reap [<target>] [flags]                  Delete an agent record.
  orch grant [<hash>]                           Approve an action an agent was refused.
  orch lock -- '<command>'                      Run a locked or gated command once orchd allows it.
  orch focus <target> [flags]                   Jump the user's view to that pane.
  orch zoom <target> [flags]                    Zoom the pane full-tab. Default: flip.
  orch move <target> --tab <tab> | --new-tab [flags]
                                                Move a pane to another tab.
  orch keys <target> <key>... [flags]           Send raw keys.
  orch pane <list>                              Raw panes, for scripts.

TABS AND SPACES
  orch tab <list|new|rename|close|focus>        Tab management.
  orch space <list|create|rename|delete|focus>  orch's own grouping of related work.

MAINTENANCE
  orch daemon <start|stop|status|reload>        The resident daemon (orchd).
  orch doctor [flags]                           Check the install and fix it.
  orch clean [flags]                            Remove dead agent dirs and orphaned worktrees.
  orch setup [flags]                            Onboarding wizard.
  orch settings [<key> <value>] [flags]         Every effective setting and its source.
  orch models [flags]                           Every model each harness can run.
  orch notify <test>                            Fire every notification sink.
  orch version                                  Installed version.
  orch help [<command>]                         This map, or one command's detail.

Target: agent name, identity key, or unique handle suffix. Tabs resolve by id or unique label.
